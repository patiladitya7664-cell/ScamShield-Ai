AGENT DIRECTORY

Specialized Intelligence. Unified Protection.

Each agent has a dedicated responsibility within the ScamShield AI ecosystem.

AGENT 01
FRAUD DETECTION

Guardian Agent

The primary fraud analysis agent. Guardian examines submitted evidence, identifies suspicious patterns and generates explainable risk assessments.

Core Responsibilities

  • Analyze suspicious messages and evidence.
  • Identify potential fraud indicators.
  • Classify potential fraud categories.
  • Explain risk scores and warning signals.
EXPECTED OUTPUT

Fraud category, risk assessment and explainable findings.

Explore Fraud Detection
AGENT 02
THREAT INTELLIGENCE

Intelligence Agent

The evidence intelligence agent extracts useful indicators from submitted evidence and organizes them for further investigation.

Core Responsibilities

  • Extract phone numbers and URLs.
  • Identify UPI IDs and related indicators.
  • Organize extracted evidence.
  • Identify possible relationships between indicators.
EXPECTED OUTPUT

Structured indicators and evidence intelligence for review.

Explore Intelligence
AGENT 03
VICTIM PROTECTION

Victim Safety Agent

A victim-first assistance agent that provides practical guidance to people facing suspected cyber fraud or financial scams.

Core Responsibilities

  • Provide immediate safety recommendations.
  • Guide users to preserve digital evidence.
  • Recommend contacting the bank when relevant.
  • Explain official cybercrime reporting options.
EXPECTED OUTPUT

Actionable safety steps and reporting guidance.

Explore Safety Support
AGENT 04
SAFE SIMULATION

Decoy Agent

A controlled simulation agent designed for cybersecurity awareness and research using synthetic scam scenarios.

Core Responsibilities

  • Generate controlled scam scenarios.
  • Demonstrate common scam techniques.
  • Support awareness and research activities.
  • Keep simulations isolated and safe.
EXPECTED OUTPUT

Synthetic scenarios and educational simulation results.
